# 부동산 시장 Dashboard (서울·부산 아파트)

서울과 부산 아파트 시장의 주간·월간 지표를 한 화면에 모은 대시보드입니다. GitHub Actions 가 매일 공개 통계를 받아
페이지를 다시 만들고 GitHub Pages 로 배포합니다: https://jhkim0603.github.io/realestate-dashboard/

work-dashboard·stockdashboard 와 같은 구조입니다(PowerShell 생성 스크립트가 `template.html` 의 자리표시자를 자료로 채우고,
받은 값을 `data-history.json` 에 쌓습니다). 일주일에 한 번 주간 요약 메일을 보냅니다(아래 '주간 메일').

## 화면

지표 이름 대신 "집값, 오르고 있나?"에 바로 답하는 순서로 놓았습니다. 위에서 아래로:

1. **지금 집값은?**(서울·부산 나란히): 최근 3개월 변동으로 정한 큰 글자(오르는 중·거의 제자리·내리는 중 등)와 기울기 화살표,
   연속 상승·하락 주와 최근 4주 속도, 1년 흐름 그래프(최근 3개월 구간만 굵게, 그 기간의 방향 색), 1년·3개월·이번 주 변동,
   "중간 가격 아파트로 치면 1년 새 약 얼마" 어림값, 집값을 올리는 쪽·내리는 쪽 신호 5개(집값·전세·거래·미분양·살 사람),
   시장 온도 점수와 월별 온도 띠.
2. **요즘 시장, 흐름 정리**(새로): 도시마다 한 줄 판정(예: "오르는 중 · 오름 속도가 크게 줄어드는 중")과 근거 문장
   (방향·속도·넓이·전환·수요·뉴스), 공통 칸(전국·금리·정책 뉴스·시·도 전환·다음 일정). 숫자와 뉴스 제목에서 화면이 자동으로 씁니다.
3. **방향과 속도**(새로): 주간 변동 막대와 4주 평균 선(오르는 힘이 세지는지 약해지는지), 같이 움직이는 구 수(오름·보합·내림 구 수의
   1년 흐름), 최근 6개월 추세 전환 기록(4주 평균이 오름·보합·내림 사이를 바꿔 3주 이상 이어진 곳), 월별 시장 온도 추이.
4. **요즘 이슈**(새로): 서울·부산·전국·정책 뉴스 제목을 주제(정책·규제, 대출·금리, 공급·정비사업, 전세·월세, 청약·분양,
   미분양·건설, 세금, 거래·매수 심리)로 세어, 이번 주 많이 나온 주제와 4주 평균 대비 증감, 12주 주제 흐름표, 기사 분위기
   (제목의 오름·내림 낱말), 주별 대표 기사, 최근 7일 기사.
5. **서울과 부산, 숫자로 나란히**: 집값·전세·월세 1년, 매달 갚는 돈, 거래량, 미분양(주택 수 대비 비율), 외지인 매입, 2030 매입을
   두 도시 칸에 작은 그래프와 함께.
6. **전국에서 보면**: 대한민국 17개 시·도 지도를 이번 주·3개월·1년 변동으로 칠하고, 순위 막대에서 서울·부산 자리를 표시.
   좁은 광역시는 바다 쪽 이름표로 빼서 잇습니다.
7. **서울·부산, 구별 지도**: 실제 구 경계(서울 25개 구와 한강, 부산 16개 구·군과 낙동강)를 4주·3개월·1년 변동으로 칠하고,
   많이 오른·내린 순 목록. 구를 누르면 그 구의 1년 매매·전세와 도시 평균 비교가 열립니다.
8. **시장은 어느 단계인가**: 집값 3개월 × 거래 1년 전 대비 사분면(지난 1년 경로), 매수우위·전세수급·전망 CSI 바늘.
9. **구별 주간 흐름**: 최근 26주 주간 변동을 칸 색으로(색이 바뀐 시점이 보임).
10. **집값 흐름(최근 3년)**: 3년·1년 누적 그래프에 정책 발표일과 기준금리 변경을 점선으로.
11. **공급·미분양**: 연도별 주택 건설 허가와 연평균·적정수요(인구 × 0.5%) 선, 미분양 추이와 주택 수 대비 비율.
12. **누가 사나·월세**: 외지인 매입 비중, 20~30대 매입 비중, 월세통합지수와 중위 월세.
13. **돈 사정**: 주담대·기준금리, 월 상환액(중위 매매가 절반을 30년 대출), 전세가율.
14. 용어 풀이, 다가오는 일정(주간 발표일은 화면이 계산, 나머지는 `config.json` 의 `events`), 아직 연결하지 않은 자료, 자료 상태.

색: 빨강은 상승(또는 집값을 올리는 쪽), 파랑은 하락(내리는 쪽). 지도 칸 색은 기간마다 고정된 경계로 3단계씩 진해집니다.
선 색은 서울 보라, 부산 청록, 전국 회색입니다. 밝은·어두운 화면을 모두 지원하고, 글꼴은 Pretendard(jsDelivr, 없으면 시스템 글꼴)입니다.

## 주간 메일

목요일에 한국부동산원 주간 통계가 나오면, 그것이 반영된 첫 실행(보통 목요일 오후~금요일 오전)에서 jhyupkim@unid.co.kr 로 한 번 보냅니다.

- 내용(순서대로): 흐름 정리(도시별 판정과 근거, 공통 칸) → 방향과 속도 그림(주간 변동·4주 평균·같이 움직이는 구 수)과 최근
  3개월 추세 전환 → 요즘 이슈(서울·부산·전국 주제 비율과 4주 평균 대비, 서울·부산 12주 주제 흐름표 그림, 기사 3건씩) →
  도시별 자세히(큰 글자, 이번 주·3개월·1년, 1년 흐름 그림, 1년 새 약 얼마, 신호 5개, 최근 4주 구별 지도) → 전국 시·도 지도와 순위 → 일정.
- 제목 예: "부동산 주간 요약 11/9 조사 · 서울 오르는 중(오름 속도가 크게 줄어드는 중) · 부산 거의 제자리(비슷한 속도로 내리는 중)".
- 만드는 곳: `tools/weekly-mail.py`(표준 라이브러리만). 흐름 정리·전환·이슈 문장은 화면이 계산해 페이지에 남긴 요약
  (`<script id="summary">`)을 크롬으로 열어(`--dump-dom`) 그대로 가져오므로 화면과 메일의 문장이 같습니다. 방향과 속도·주제 흐름표
  그림은 대시보드를 `#mailshot-trend`, `#mailshot-issues-seoul` 처럼 열면 그 그림만 폭 600 으로 그려지는 것을 크롬으로 찍습니다.
  도시별 그림(1년 흐름, 구별 지도)은 SVG 를 그려 찍습니다. 첨부한 PNG 는 본문에서 `cid:` 로 부릅니다.
- 한 주에 한 번: 실제로 보낸 주(ISO 주, KST)를 `.last-weekly-mail` 에 적어 커밋합니다. 보내기에 실패하면 적지 않아 다음 실행이
  다시 보냅니다. 발표가 없던 주(명절 등)는 일요일에 지난 자료로 보냅니다. main 이 아닌 브랜치에서는 보내지 않습니다.
- 필요한 비밀값: 저장소 Settings → Secrets 의 `GMAIL_USERNAME`, `GMAIL_APP_PASSWORD`(work·stock 과 같은 Gmail 앱 비밀번호).
  없으면 메일 단계만 건너뜁니다.
- 수동 실행: `gh workflow run update-dashboard.yml -f send_email=false`(메일 없이 화면만),
  `-f force_email=true`(지금 한 통 시험 발송, 보냄 표시를 남기지 않아 그 주 정기 메일은 그대로 나감),
  `-f send_email=false -f mail_preview=true`(보내지 않고 본문·그림을 실행 결과로 받기).

## 자료 (모두 인증키 없이)

| 자료 | 출처 | 주기 |
|---|---|---|
| 주간 아파트 매매·전세가격지수, 매수우위지수, 전세수급지수(서울·부산·구, 전국 17개 시·도 매매) | 한국부동산원 R-ONE 공개 API | 매주 목요일(그 주 월요일 기준) |
| 월간 중위 매매가격, 전세가율, 아파트 매매거래 건수, 월세통합지수, 중위 월세, 매입자 거주지별·연령대별 매매거래 | 한국부동산원 R-ONE 공개 API | 매월 |
| 주택담보대출 금리, 기준금리, 미분양, 인허가, 주택가격전망 CSI | 한국은행 ECOS 공개 API(sample 키) | 매월 |
| 주택 수(주택보유수, 미분양 비율의 분모) | 한국은행 ECOS 901Y106 | 매년 |
| 주민등록 인구(적정수요 선) | 행정안전부, `config.json` 의 `population` 에 직접 적음 | 해마다 고침 |
| 뉴스 제목(서울·부산·전국 정책 묶음별 검색어, 최근 7일) → 주별 주제 수 | 구글 뉴스 RSS | 실행할 때마다 더해 `news-history.json` 에 쌓음 |
| 지도 경계(시·도, 서울·부산 구) | 통계청 SGIS 행정구역 2018(공공누리 제1유형), [southkorea-maps](https://github.com/southkorea/southkorea-maps) | 고정 |

- R-ONE 은 인증키가 없으면 한 번에 5행만 주고 페이지 번호도 무시합니다. 그래서 지역 코드(CLS_ID)와 기간(START/END_WRTTIME)을
  좁혀 5행씩 이어 받습니다. 처음 실행은 도시 지수 160주, 권역·구 56주를 채우느라 1,500번쯤 부르고, 그 뒤에는 최근 몇 주·몇 달만
  다시 받습니다. 통계표 ID 와 지역 코드는 `config.json` 에 있습니다(주간 표는 5자리, 월간 표는 6자리이고 표마다 번호가 다릅니다).
- R-ONE 서버는 중간 인증서를 보내지 않습니다. 워크플로가 `certs/turingsign-rsa-secure-ca3.crt`(발급처 WISeKey 가 공개한 중간
  인증서, 2029-02-24 까지 유효)를 러너의 신뢰 목록에 더해 체인을 완성합니다. 인증서 검증은 끄지 않습니다.
- 한국부동산원 월간 지수를 옮긴 ECOS 표(901Y113 등)는 2026년 1월에서 멈춰 있어 쓰지 않고, R-ONE 에서 직접 받습니다.
  ECOS 의 월세 지수 표(901Y115)도 같은 이유로 쓰지 않고 R-ONE 월세통합지수(A_2024_00054)를 받습니다.
- 매입자 거주지별(A_2024_00609)·연령대별(A_2024_00610) 표는 지역을 `CLS_ID` 가 아니라 `GRP_ID`(서울 900002, 부산 900003)로
  고르고, `CLS_ID` 가 분류(합계·관할 시도 밖 등)입니다. 그룹 번호는 통계표 항목 목록 API(`SttsApiTblItm.do`, `ITM_TAG=그룹`)에서 찾았습니다.
  두 표의 합계는 같아 합계는 거주지별 표에서만 받습니다.
- 전국 지도용 시·도 코드는 주간 표의 지역 번호를 하나씩 불러 찾았습니다(`config.json` 의 `provinces`). 광주·전남은 R-ONE 에서
  '전남광주' 아래로 묶여 있지만 지도에는 따로 칠합니다.

## 파일

- `Update-RealEstateDashboard.ps1`: 자료를 받아 `data-history.json` 에 쌓고 `dashboard.html` 을 만듭니다(pwsh 7).
- `template.html`: 화면. 변동률·연속 주·시장 온도·국면·지도 색·월 상환액 등 계산은 이 안의 스크립트가 합니다.
  자리표시자는 `__DATA_JSON__`(자료)과 `__GEO_JSON__`(지도) 두 개입니다.
- `geo/maps.json`: 지도 경계를 화면 좌표(SVG path)로 줄인 것(80KB). `tools/build-geo.py` 로 다시 만듭니다.
- `tools/build-geo.py`: southkorea-maps 의 TopoJSON 을 받아 경계선마다 줄이고(이웃 구끼리 틈이 생기지 않음), 이름표 자리(구 안에서
  경계와 가장 먼 점)와 한강·낙동강 선(강 한가운데를 지나는 구 경계)을 만듭니다. 좁은 구의 바다 쪽 이름표 자리는 `template.html` 의 `CALL`.
- `config.json`: 통계표 ID, 지역 코드, ECOS 항목 코드, 시·도 코드, 인구, 정책 발표일(`policies`), 일정(`events`), 뉴스 검색어와 거르는 낱말.
- `data-history.json`: 받은 값(봇이 커밋).
- `tools/weekly-mail.py`: 주간 메일 본문(`email-summary.html`)·제목(`email-subject.txt`)·그림(`mail-charts/*.png`)을 만듭니다. 만든 파일은 커밋하지 않습니다.
- `.last-weekly-mail`: 마지막으로 주간 메일을 보낸 주(봇이 커밋).
- `news-history.json`: 주(월요일 날짜)마다 묶음별 기사 수·주제별 수·대표 기사 3개, 최근 기사 목록(봇이 커밋). 이번 주·지난주만 제목 지문(ids)을 두어 같은 기사를 두 번 세지 않습니다.
- `tools/news-backfill.py`: 뉴스 지난 주들을 채우는 스크립트(내 PC 에서 한 번). 구글이 GitHub 실행 환경의 지난 주 검색(after:/before:)을 503 으로 막아서입니다.
- `.github/workflows/update-dashboard.yml`: 하루 두 번(KST 14:17, 06:43 예약, 실제로는 몇 시간 늦게 시작) 실행, 주간 메일, Pages 배포.

## 기록

- **2026-11-16 추세와 이슈(8차).** 사용자 요청: "요새 부동산 시장이 어떤 이슈가 있고 어떤 방향으로 움직이는지 추이를 보고 싶다".
  - 흐름 정리: 판정은 최근 3개월 변동(큰 글자) + 4주 평균 주간 변동을 3개월 전과 비교한 속도(빨라짐·줄어듦·비슷·돌아섬).
    보합은 4주 평균 ±0.01% 안쪽(부산처럼 주 0.01~0.02%씩 움직이는 곳도 방향이 보이게).
  - 넓이: 구마다 4주 평균으로 오름·보합·내림을 정해 주마다 센 수. 전환: 상태가 바뀌어 3주 이상 이어진 때(최근 2주째면 '새로').
    흐름 정리의 '전환' 문장은 구마다 최근 3개월 안의 마지막 전환만 씁니다(부산처럼 0 근처에서 자주 바뀌는 곳이 길어지지 않게).
