# 부동산 시장 Dashboard (서울·부산 아파트)

서울과 부산 아파트 시장의 주간·월간 지표를 한 화면에 모은 대시보드입니다. GitHub Actions 가 매일 공개 통계를 받아
페이지를 다시 만들고 GitHub Pages 로 배포합니다: https://jhkim0603.github.io/realestate-dashboard/

work-dashboard·stockdashboard 와 같은 구조입니다(PowerShell 생성 스크립트가 `template.html` 의 자리표시자를 자료로 채우고,
받은 값을 `data-history.json` 에 쌓습니다).

## 화면

- **핵심 요약**: 서울·부산·전국 아파트 매매가격의 이번 주 변동률, 연속 상승·하락 주, 4주·12주·52주 누적, 최근 26주 주간 변동률 막대,
  전세 변동률, 매수우위지수. 이번 주 구별 상승·보합·하락 수.
- **주간 흐름**: 같은 출발점에서 본 누적 변동률(서울·부산 매매/전세, 전국 매매, 13주·26주·1년·3년), 매수우위지수와 전세수급지수.
- **구별 동향**: 서울 25개 구, 부산 16개 구·군과 권역의 이번 주·4주·12주·52주 매매 변동률, 이번 주·12주 전세 변동률, 26주 막대.
  머리글을 누르면 정렬합니다.
- **가격·거래(월간)**: 아파트 중위 매매가격, 전세가율, 매매거래 건수.
- **금리·공급·심리(월간)**: 주택담보대출 금리와 기준금리, 미분양 주택, 주택 건설 인허가(12개월 합계), 주택가격전망 CSI.

색: 빨강은 상승, 파랑은 하락(국내 시세 화면 관례). 선 색은 서울 보라, 부산 청록, 전국 회색입니다. 밝은·어두운 화면을 모두 지원합니다.

## 자료 (모두 인증키 없이)

| 자료 | 출처 | 주기 |
|---|---|---|
| 주간 아파트 매매·전세가격지수, 매수우위지수, 전세수급지수 | 한국부동산원 R-ONE 공개 API | 매주 목요일(그 주 월요일 기준) |
| 월간 중위 매매가격, 전세가율, 아파트 매매거래 건수 | 한국부동산원 R-ONE 공개 API | 매월 |
| 주택담보대출 금리, 기준금리, 미분양, 인허가, 주택가격전망 CSI | 한국은행 ECOS 공개 API(sample 키) | 매월 |

- R-ONE 은 인증키가 없으면 한 번에 5행만 주고 페이지 번호도 무시합니다. 그래서 지역 코드(CLS_ID)와 기간(START/END_WRTTIME)을
  좁혀 5행씩 이어 받습니다. 처음 실행은 도시 지수 160주, 권역·구 56주를 채우느라 1,500번쯤 부르고, 그 뒤에는 최근 몇 주·몇 달만
  다시 받습니다. 통계표 ID 와 지역 코드는 `config.json` 에 있습니다(주간 표는 5자리, 월간 표는 6자리이고 표마다 번호가 다릅니다).
- R-ONE 서버는 중간 인증서를 보내지 않습니다. 워크플로가 `certs/turingsign-rsa-secure-ca3.crt`(발급처 WISeKey 가 공개한 중간
  인증서, 2029-02-24 까지 유효)를 러너의 신뢰 목록에 더해 체인을 완성합니다. 인증서 검증은 끄지 않습니다.
- 한국부동산원 월간 지수를 옮긴 ECOS 표(901Y113 등)는 2026년 1월에서 멈춰 있어 쓰지 않고, R-ONE 에서 직접 받습니다.

## 파일

- `Update-RealEstateDashboard.ps1`: 자료를 받아 `data-history.json` 에 쌓고 `dashboard.html` 을 만듭니다(pwsh 7).
- `template.html`: 화면. 변동률·연속 주·누적·구별 표 계산은 이 안의 스크립트가 합니다.
- `config.json`: 통계표 ID, 지역 코드, ECOS 항목 코드.
- `data-history.json`: 받은 값(봇이 커밋).
- `.github/workflows/update-dashboard.yml`: 하루 두 번(KST 14:17, 06:43 예약, 실제로는 몇 시간 늦게 시작) 실행과 Pages 배포.
